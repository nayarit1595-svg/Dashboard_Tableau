# 📊 Análisis de Inventario Muerto - Tableau Dashboard

## 📌 Descripción del Proyecto
Este proyecto analiza el impacto financiero y el volumen del **inventario estancado (inventario muerto)** para identificar oportunidades de optimización en la gestión de almacén y liberar capital de trabajo.

![Vista Previa del Dashboard](Captura%20de%20pantalla%202026-07-27%20135150.png)

---

## 🎯 Objetivos Principales
* **Identificar Top Productos:** Determinar cuáles SKUs concentran el mayor costo monetario en almacén sin movimiento.
* **Evaluar Volumen de Piezas:** Analizar el conteo de unidades estancadas por categoría y producto.
* **Optimización Financiera:** Proporcionar visibilidad para la toma de decisiones estratégicas.

---

## 🛠️ Herramientas Utilizadas
* **Tableau:** Visualización interactiva y dashboards empresariales.
* **SQL:** Extracción y filtrado preliminar de datos de inventario.
